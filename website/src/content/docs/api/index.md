The API reference — `createCalendar`, the calendar instance, the kernel, the
commands, the framework components — will be generated from the TypeScript
types, so that it never drifts from the code.

:::note[Being written]
Until then, the types themselves are the reference: `packages/dom/src/calendar.ts`
(`CalendarOptions`, `CalendarUpdate`, `CalendarInstance`) and
`packages/core/src/index.ts`. The commands are described by a JSON Schema,
[`site/commands.schema.json`](https://github.com/plinthworks/dzcalendar/blob/main/site/commands.schema.json).
:::
