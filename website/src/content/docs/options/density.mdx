How much room the calendar's rows and paddings take.

<OptionFacts name="density" />

## What it does

`'compact'`, `'comfortable'` (the default) or `'spacious'`: an hour of a time
grid is 48, 72 or 96 px tall, and the height of the bars and the day heads,
the month's weeks and the type size follow. A narrow side panel takes
compact, a wall screen spacious. `--dz-minute` (the pixels of a minute) and
the other `--dz-*` variables set any other size — on `.dz-cal` itself, since
a density sets them there.

## Example

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, { timeZone: 'Europe/Paris', density: 'compact' });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" density="compact" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" density="compact" />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" density="compact" />
</template>
```

</Fragment>
</CodeTabs>

In the frameworks it is an Angular input (`density`) and a React and Vue prop (`density`, `density`).
