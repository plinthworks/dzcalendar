The row above a time grid's hours where all-day events go.

<OptionFacts name="allDaySlot" />

## What it does

In a week or a day view, all-day events (a day off, a conference) sit in a
row above the hours. False removes the row: the hours start at the top.

Without the row, all-day events are not drawn in the time grid — a day off
would be invisible. The calendar says so (`events-not-drawn`, through
`onProblem` or the console). An all-day *background* event still washes its
columns. Its label is the application's through `hooks.allDayLabel`.

## Example

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, {
  timeZone: 'Europe/Paris',
  allDaySlot: false,
  events: [{ id: 'off', title: 'Day off', start: '2026-10-23', allDay: true }],
  // Said once (events-not-drawn): this day off is not drawn in the week.
  onProblem: (problem) => console.warn(problem.code, problem.detail),
});
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" [options]="{ allDaySlot: false }" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" allDaySlot={false} />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" :options="{ allDaySlot: false }" />
</template>
```

</Fragment>
</CodeTabs>

In Angular and Vue it goes in `options`; in React it is a prop.
