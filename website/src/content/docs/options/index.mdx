`createCalendar(element, options)` takes one object of options. Most of them
can change afterwards with `calendar.update({ … })`; the frameworks pass them
as inputs, props or an `options` object.

Each option has its own page: what it does, its type and default, whether it
changes live, an example in JavaScript, Angular, React and Vue, and a live
demo. The options whose page is written have a link; the others come in batches.
