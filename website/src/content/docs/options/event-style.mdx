How events are drawn: tinted with their tone's edge, or as filled blocks.

<OptionFacts name="eventStyle" />

## What it does

- `'tinted'` (the default): a light wash of the event's tone with a strong
  edge on its start side — easy to read, quiet on a busy week.
- `'solid'`: a block filled with the tone, its text on it — the classic look.

An event's `tone` (a name of the theme's `tones`) or its own colours choose
the tone; `--dz-event-tint`, `--dz-event-shade` and `--dz-event-edge` tune
the tinted look.

## Example

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, { timeZone: 'Europe/Paris', eventStyle: 'solid' });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" [options]="{ eventStyle: 'solid' }" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" eventStyle="solid" />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" :options="{ eventStyle: 'solid' }" />
</template>
```

</Fragment>
</CodeTabs>

In Angular and Vue it goes in `options`; in React it is a prop.
