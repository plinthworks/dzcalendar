Whether an event shows its time beside its title.

<OptionFacts name="displayEventTime" />

## What it does

A timed event shows its time beside its title: its start and end in a time
grid (`09:00 – 09:45`), its start in a month. With `false`, the title alone — for a grid
whose hours already say it, or a month of short labels.

All-day events never show a time. How the time is written is `formats`'
(`formats: { eventTime: … }`), and the whole content is the application's
through `hooks.event`.

## Example

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, { timeZone: 'Europe/Paris', initialView: 'dayGridMonth', displayEventTime: false });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" view="dayGridMonth" [options]="{ displayEventTime: false }" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" defaultView="dayGridMonth" displayEventTime={false} />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" view="dayGridMonth" :options="{ displayEventTime: false }" />
</template>
```

</Fragment>
</CodeTabs>

In Angular and Vue it goes in `options`; in React it is a prop.
