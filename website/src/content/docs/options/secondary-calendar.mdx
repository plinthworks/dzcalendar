A second calendar's date shown beside each date — the Hijri under the Gregorian.

<OptionFacts name="secondaryCalendar" />

## What it does

Each day cell and each day's heading shows its date in this calendar too,
small, beside the first one (`displayCalendar` or the locale's). It serves
two readers at once: a clinic in Algiers whose patients count in both. Any
of the platform's calendars (an unknown name throws a `RangeError`); `null`
(the default) none, and nothing is shown when it is the calendar the dates
are already written in.

## Example

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, { timeZone: 'Africa/Algiers', locale: 'fr-DZ', initialView: 'dayGridMonth', secondaryCalendar: 'islamic-umalqura' });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" secondaryCalendar="islamic-umalqura" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" secondaryCalendar="islamic-umalqura" />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" secondary-calendar="islamic-umalqura" />
</template>
```

</Fragment>
</CodeTabs>

In the frameworks it is an Angular input (`secondaryCalendar`) and a React and Vue prop (`secondaryCalendar`, `secondary-calendar`).
