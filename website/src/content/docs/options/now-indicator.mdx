A line across the time grid at the current time, moved every minute.

<OptionFacts name="nowIndicator" />

## What it does

In a week or a day view, a line marks now across today's column, when
today is shown. It moves on every minute, from the device's clock. With
`false`, no line — in the Pro's timeline either.

Its look is the application's through `hooks.nowIndicator`; its colour is
the theme's `--dz-now` token.

## Example

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

const calendar = createCalendar(element, { timeZone: 'Europe/Paris', initialView: 'timeGridDay' });

// Later: no line (a printout, a past period).
calendar.update({ nowIndicator: false });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" [options]="{ nowIndicator: false }" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" nowIndicator={false} />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" :options="{ nowIndicator: false }" />
</template>
```

</Fragment>
</CodeTabs>

In Angular and Vue it goes in `options`; in React it is a prop.
