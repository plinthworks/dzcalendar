La place que prennent les rangées et les marges du calendrier.

<OptionFacts name="density" />

## Ce qu'elle fait

`'compact'`, `'comfortable'` (par défaut) ou `'spacious'` : une heure d'une
grille horaire fait 48, 72 ou 96 px de haut, et la hauteur des barres et des
en-têtes de jour, les semaines du mois et la taille du texte suivent. Un
panneau latéral étroit prend compact, un écran mural spacious. `--dz-minute`
(les pixels d'une minute) et les autres variables `--dz-*` fixent toute autre
taille — sur `.dz-cal` lui-même, puisqu'une densité les y fixe.

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, { timeZone: 'Europe/Paris', density: 'compact' });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" density="compact" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" density="compact" />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" density="compact" />
</template>
```

</Fragment>
</CodeTabs>

Dans les frameworks, c'est une entrée en Angular (`density`) et une prop en React (`density`) et en Vue (`density`).
