La date dont le calendrier montre la période en premier.

<OptionFacts name="initialDate" />

## Ce qu'elle fait

Le calendrier s'ouvre sur la période qui contient cette date : son mois, sa
semaine, son jour. Sans elle, c'est aujourd'hui dans `timeZone`. Ensuite la
personne se déplace avec les flèches de l'en-tête et « aujourd'hui », et votre
code avec `update({ date })` ou `navigate('prev' | 'next' | 'today')`.

C'est un `Temporal.PlainDate` — une date sans heure ni fuseau, lue comme ce
jour dans le fuseau du calendrier. Attendez `loadTemporal()` avant d'en créer
une : sur un navigateur sans Temporal natif, son polyfill arrive à ce moment.

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { Temporal, loadTemporal } from '@dzcalendar/core';
import { createCalendar } from '@dzcalendar/dom';

await loadTemporal();
const calendar = createCalendar(element, {
  timeZone: 'Europe/Paris',
  initialDate: Temporal.PlainDate.from('2026-10-25'),
});

// Later: another period.
calendar.update({ date: Temporal.PlainDate.from('2026-12-01') });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component, signal } from '@angular/core';
import { Temporal } from '@dzcalendar/core';
import type { PlainDate } from '@dzcalendar/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `
    <dz-calendar timeZone="Europe/Paris" [(date)]="date" />
    <p>Showing {{ date()?.toString() }}</p>`,
})
export class Agenda {
  // The first date; it follows the person's moves (two-way).
  readonly date = signal<PlainDate | undefined>(Temporal.PlainDate.from('2026-10-25'));
}
```

</Fragment>
<Fragment slot="react">

```tsx
import { Temporal } from '@dzcalendar/core';
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" defaultDate={Temporal.PlainDate.from('2026-10-25')} />;

```

<Fragment slot="vue">

```vue
<script setup lang="ts">
import { shallowRef } from 'vue';
import { Temporal } from '@dzcalendar/core';
import type { PlainDate } from '@dzcalendar/core';
import { DzCalendar } from '@dzcalendar/vue';

const date = shallowRef<PlainDate>(Temporal.PlainDate.from('2026-10-25'));

  <DzCalendar time-zone="Europe/Paris" v-model:date="date" />
```

Dans les frameworks, c'est la date du composant : `[(date)]` en Angular, `defaultDate` en React (ou `date` avec `onDateChange`, contrôlée), `v-model:date` en Vue.
Leur `Temporal.PlainDate.from(…)` s'exécute avec le composant : sur Safari,
attendez d'abord `loadTemporal()` une fois au démarrage (le `provideDzCalendar()`
d'Angular le fait ; [React](../../getting-started/react/#temporal-dabord),
[Vue](../../getting-started/vue/#temporal-dabord)).
