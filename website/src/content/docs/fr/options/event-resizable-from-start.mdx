Permet de redimensionner un événement par son début, et pas seulement par sa fin.

<OptionFacts name="eventResizableFromStart" />

## Ce qu'elle fait

Sans cette option, un événement (horaire ou d'une journée entière) ne se
redimensionne que par sa fin ; avec elle, par son début aussi : un
rendez-vous avancé en tirant son haut, la barre d'un congrès dans un mois
étirée d'un jour vers l'arrière. Au clavier, Alt+Maj+flèches tirent le début
d'un événement saisi.

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, { timeZone: 'Europe/Paris', editable: true, eventResizableFromStart: true });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" [editable]="true" [options]="{ eventResizableFromStart: true }" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" editable eventResizableFromStart />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" editable :options="{ eventResizableFromStart: true }" />
</template>
```

</Fragment>
</CodeTabs>

En Angular et en Vue elle va dans `options` ; en React c'est une prop.
