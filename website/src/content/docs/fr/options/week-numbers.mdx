Montre le numéro de chaque semaine : au début des rangées d'un mois, dans le coin d'une vue semaine.

<OptionFacts name="weekNumbers" />

## Ce qu'elle fait

Les semaines sont numérotées selon les règles de la locale, ou selon
`firstDay` quand il est donné, avec le nombre minimal de jours de la locale :
les semaines ISO (lundi, une première semaine qui compte 4 jours) dans la
plupart de l'Europe, les semaines du dimanche où la première semaine contient
le 1er janvier aux États-Unis. Une date avant la semaine 1 appartient à la
dernière semaine de l'année précédente.

L'apparence du numéro est celle de l'application avec `hooks.weekNumber` (un
lien vers la semaine, un autre libellé).

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

createCalendar(element, { timeZone: 'Europe/Paris', initialView: 'dayGridMonth', weekNumbers: true });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" view="dayGridMonth" [weekNumbers]="true" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" defaultView="dayGridMonth" weekNumbers />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" view="dayGridMonth" week-numbers />
</template>
```

</Fragment>
</CodeTabs>

Dans les frameworks, c'est une entrée : `weekNumbers` en Angular, `weekNumbers` en React, `week-numbers` en Vue.
