Le jour où commencent les semaines, en jour ISO : 1 est lundi, 7 est dimanche.

<OptionFacts name="firstDay" />

## Ce qu'elle fait

L'option décide où commence une vue semaine, la première colonne d'un mois, et la
numérotation des semaines. Sans elle, c'est celui de la locale : lundi dans la
plupart de l'Europe, dimanche aux États-Unis, samedi dans une grande partie du
monde arabophone.

Les nombres sont des jours ISO, comme partout dans DzCalendar (`hiddenDays`,
`businessHours`) : 1 lundi … 7 dimanche — pas le 0 à 6 du `Date` de
JavaScript. `update({ firstDay: null })` revient à celui de la locale.

<Aside type="caution">
Une valeur qui n'est pas un entier de 1 à 7 lève une `RangeError` à `createCalendar` ou `update()`, et rien ne change.
</Aside>

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

const calendar = createCalendar(element, { timeZone: 'America/New_York', initialView: 'dayGridMonth', firstDay: 7 });

// Later: back to the locale's.
calendar.update({ firstDay: null });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="America/New_York" view="dayGridMonth" [options]="{ firstDay: 7 }" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="America/New_York" defaultView="dayGridMonth" firstDay={7} />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="America/New_York" view="dayGridMonth" :options="{ firstDay: 7 }" />
</template>
```

</Fragment>
</CodeTabs>

En Angular et en Vue il va dans `options` ; en React c'est une prop.
