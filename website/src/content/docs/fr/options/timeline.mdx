L'échelle et les couloirs des vues timeline du Pro (`import '@dzcalendar/pro'`).

<OptionFacts name="timeline" />

## Ce qu'elle fait

La timeline dessine le temps en travers, une ligne par ressource
(`resourceTimelineDay`, `…Week`, `…Month`, `…Year`) ou une seule ligne pour
tout (`timelineDay`…). Cinq réglages, fusionnés clé par clé avec
`update({ timeline })` — `slot: undefined` revient à la valeur par défaut :

- `slot` : la largeur d'un créneau en temps.
- `maxLanes` : les couloirs de la ligne d'une ressource ; le dernier porte
  « +N » quand plus d'événements se chevauchent.
- `fillLanes` : les couloirs d'une timeline sans ressources — une valeur de
  départ : dans un navigateur, sa ligne unique remplit la vue et les couloirs
  sont mesurés.
- `step` : ce dont ◀ ▶ font glisser la timeline (`{ minutes: 15 }`,
  `{ hours: 1 }`) au lieu de changer de période.
- `follow` : la timeline garde l'instant présent à l'écran à mesure que le
  temps passe.

Un créneau en minutes doit diviser un jour, et les couloirs sont des entiers
de 1 ou plus ; un pas s'écrit en heures et en minutes, plus long que rien ;
toute autre valeur lève une `RangeError` à la création ou à
`update()`. Un créneau d'horloge qui traverse
un changement d'heure garde sa vraie largeur. La largeur à l'écran est celle
de la feuille de style (`--dz-tl-slot`) ; les colonnes de la zone des
ressources sont `viewOptions.timeline.areaColumns`.

## Ses membres

### `fillLanes`

<OptionFacts name="timeline.fillLanes" />

Les couloirs d'une timeline sans ressources, avant la mesure : dans un navigateur, sa ligne unique a la hauteur de la vue et tient autant de couloirs que la place le permet.

### `follow`

<OptionFacts name="timeline.follow" />

L'instant présent reste à l'écran, aux trois quarts du temps montré, déplacé chaque minute ; passé la fin de la période (minuit sur une timeline d'un jour), la suivante arrive. Le suivi se met en pause dès que la personne se déplace dans le temps — un défilement, un glissement, une autre période — et « Aujourd'hui » (`navigate('today')`) le reprend. Pensé pour la supervision : une timeline qui montre ce qui tourne maintenant.

### `maxLanes`

<OptionFacts name="timeline.maxLanes" />

Les événements qui se chevauchent que la ligne d'une ressource empile ; au-delà, son dernier couloir porte « +N », qui ouvre le reste.

### `slot`

<OptionFacts name="timeline.slot" />

Des minutes par créneau (un diviseur du jour : 15, 30, 60, 120…) ou `'day'`. Par défaut 30 minutes pour un jour, une heure jusqu'à une semaine, un jour au-delà.

### `step`

<OptionFacts name="timeline.step" />

Des heures et des minutes (`{ minutes: 15 }`, `{ hours: 1 }`, `'PT30M'`). Avec lui, ◀ ▶ et `navigate('prev' | 'next')` font défiler la timeline d'autant ; au bout de l'axe, la période suivante ou précédente arrive, là où allait le glissement. Une vue d'un jour s'arrête à minuit en chemin ; une vue de plusieurs jours (`views: { supervision: { family: 'timeline', duration: { days: 3 } } }`) le traverse. `calendar.shift({ minutes: -45 })` fait glisser de n'importe quel autre nombre d'heures et de minutes (un jour ou plus, ou rien, lève une `RangeError`, comme l'option). Un jour ou plus, c'est le `dateIncrement` d'une vue, pas un pas.

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';
import '@dzcalendar/pro';

const calendar = createCalendar(element, {
  timeZone: 'Europe/Paris',
  initialView: 'resourceTimelineWeek',
  resources: [{ id: 'benali', title: 'Dr Benali' }, { id: 'room1', title: 'Room 1' }],
  timeline: { slot: 120, maxLanes: 2 },
});

// Later: back to the default slot, lanes unchanged.
calendar.update({ timeline: { slot: undefined } });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';
import '@dzcalendar/pro';

@Component({
  selector: 'app-planning',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" view="resourceTimelineWeek" [resources]="staff" [options]="{ timeline: { slot: 120 } }" />`,
})
export class Planning {
  readonly staff = [{ id: 'benali', title: 'Dr Benali' }, { id: 'room1', title: 'Room 1' }];
}
```

</Fragment>
<Fragment slot="react">

import { DzCalendar } from '@dzcalendar/react';
import '@dzcalendar/pro';

const STAFF = [{ id: 'benali', title: 'Dr Benali' }, { id: 'room1', title: 'Room 1' }];

export function Planning() {
  return <DzCalendar timeZone="Europe/Paris" defaultView="resourceTimelineWeek" resources={STAFF} timeline={{ slot: 120 }} />;

En Angular et en Vue elle va dans `options` ; en React c'est une prop.
