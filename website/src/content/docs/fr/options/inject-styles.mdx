Si le calendrier ajoute sa propre feuille de style à la page (ou à sa racine shadow).

<OptionFacts name="injectStyles" />

## Ce qu'elle fait

La CSS structurelle du calendrier — grilles, positions, tailles — est mise
dans la page une fois, dans un `<style>`, pour qu'un calendrier fonctionne
sans rien d'autre à inclure. Une page sous une politique de sécurité (CSP)
sans styles en ligne ne peut pas la prendre : mettez `false` et incluez
vous-même `DZ_CSS` (exportée par `@dzcalendar/dom`), dans une feuille de style
que votre politique autorise, avec la CSS du thème, toute famille faite avec
`defineTheme` (`themeCss(name)`), les feuilles des entrées utilisées
(`LIST_CSS`, `MULTIMONTH_CSS`, la timeline et l'éditeur du Pro) et, avec
`look: 'none'`, `lookGuardedCss(…)`.

Elle est lue à la création du calendrier.

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar, DZ_CSS } from '@dzcalendar/dom';

// Written once into a stylesheet the page's policy allows (a build step), not injected at run time.
console.log(DZ_CSS.length);
createCalendar(element, { timeZone: 'Europe/Paris', injectStyles: false });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR, DZ_CALENDAR_DEFAULTS } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  providers: [{ provide: DZ_CALENDAR_DEFAULTS, useValue: { injectStyles: false } }],
  template: `<dz-calendar timeZone="Europe/Paris"  />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" initial={{ injectStyles: false }} />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" :initial="{ injectStyles: false }" />
</template>
```

</Fragment>
</CodeTabs>

Elle est lue à la création du calendrier : en Angular par les valeurs par défaut (`DZ_CALENDAR_DEFAULTS`, `provideDzCalendar`), en React et en Vue par `initial`.
