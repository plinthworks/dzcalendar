Le fuseau IANA dans lequel le calendrier dessine ses jours et ses heures.

<OptionFacts name="timeZone" />

## Ce qu'elle fait

Chaque événement garde son propre fuseau : `2026-10-22T10:00[America/Chicago]`
est dix heures à Chicago, quoi que montre le calendrier. `timeZone` décide où
ce moment tombe à l'écran — à 17:00 dans un calendrier réglé sur
`'Europe/Paris'`, à 10:00 dans un calendrier réglé sur `'America/Chicago'`.
Les jours sont ceux de ce fuseau : un jour de 23 ou 25 heures quand ses
horloges changent.

Donnez un nom IANA (`'Europe/Paris'`, `'Africa/Algiers'`, `'UTC'`), jamais un
simple décalage : un décalage n'a pas de changement d'heure. Sans lui, le
calendrier prend le fuseau du navigateur et le signale une fois
(`zone-from-browser`, par `onProblem` ou la console) — un téléphone réglé sur
Tokyo dessinerait 14:00 à Alger à 22:00. Passez `Temporal.Now.timeZoneId()`
quand c'est bien le fuseau du navigateur que vous voulez.

<Aside type="caution">
Un nom qui n'est pas un fuseau lève une `RangeError` à `createCalendar` ou `update()`, et rien ne change.
</Aside>

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

const calendar = createCalendar(element, {
  timeZone: 'Europe/Paris',
  events: [{ id: 'call', title: 'Call Chicago', start: '2026-10-22T10:00[America/Chicago]', duration: { hours: 1 } }],
});

// Later: the same events, drawn in Chicago's hours.
calendar.update({ timeZone: 'America/Chicago' });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component, signal } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `
    <select (change)="zone.set($any($event.target).value)">
      <option value="Europe/Paris">Paris</option>
      <option value="America/Chicago">Chicago</option>
    </select>
    <dz-calendar [timeZone]="zone()" />`,
})
export class Agenda {
  readonly zone = signal('Europe/Paris');
}
```

</Fragment>
<Fragment slot="react">

```tsx
import { useState } from 'react';
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  const [zone, setZone] = useState('Europe/Paris');
  return (
    <>
      <select value={zone} onChange={(e) => setZone(e.target.value)}>
        <option value="Europe/Paris">Paris</option>
        <option value="America/Chicago">Chicago</option>
      </select>
      <DzCalendar timeZone={zone} />
    </>
  );
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DzCalendar } from '@dzcalendar/vue';

const zone = ref('Europe/Paris');
</script>

<template>
  <select v-model="zone">
    <option value="Europe/Paris">Paris</option>
    <option value="America/Chicago">Chicago</option>
  </select>
  <DzCalendar :time-zone="zone" />
</template>
```

</Fragment>
</CodeTabs>

Dans les frameworks, c'est une entrée : `timeZone` en Angular, `timeZone` en React, `time-zone` en Vue.
