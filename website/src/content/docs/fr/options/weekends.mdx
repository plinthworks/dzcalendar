Avec `false`, le samedi et le dimanche sont écartés de toutes les vues.

<OptionFacts name="weekends" />

## Ce qu'elle fait

`weekends: false`, c'est `hiddenDays` avec 6 et 7 ajoutés : une semaine de
cinq jours, un mois de cinq colonnes. Les deux se combinent —
`weekends: false` avec `hiddenDays: [3]` montre lundi, mardi, jeudi et
vendredi.

Samedi et dimanche sont ici les jours ISO 6 et 7, quelle que soit la locale :
là où le week-end tombe le vendredi et le samedi, masquez plutôt `[5, 6]`
avec `hiddenDays`.

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

const calendar = createCalendar(element, { timeZone: 'Europe/Paris', weekends: false });

// Later: the whole week.
calendar.update({ weekends: true });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component, signal } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `
    <label><input type="checkbox" [checked]="weekends()" (change)="weekends.set(!weekends())" /> Weekends</label>
    <dz-calendar timeZone="Europe/Paris" [weekends]="weekends()" />`,
})
export class Agenda {
  readonly weekends = signal(false);
}
```

</Fragment>
<Fragment slot="react">

```tsx
import { useState } from 'react';
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  const [weekends, setWeekends] = useState(false);
  return (
    <>
      <label>
        <input type="checkbox" checked={weekends} onChange={() => setWeekends(!weekends)} /> Weekends
      </label>
      <DzCalendar timeZone="Europe/Paris" weekends={weekends} />
    </>
  );
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DzCalendar } from '@dzcalendar/vue';

const weekends = ref(false);
</script>

<template>
  <label><input v-model="weekends" type="checkbox" /> Weekends</label>
  <DzCalendar time-zone="Europe/Paris" :weekends="weekends" />
</template>
```

</Fragment>
</CodeTabs>

Dans les frameworks, c'est une entrée : `weekends` en Angular, en React et en Vue.
