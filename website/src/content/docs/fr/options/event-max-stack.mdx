Combien d'événements qui se chevauchent une grille horaire dessine côte à côte avant « +N ».

<OptionFacts name="eventMaxStack" />

## Ce qu'elle fait

Les événements à la même heure se partagent la largeur de leur colonne.
Au-delà de ce nombre, la colonne garde un couloir de moins et met le reste
derrière un « +N » dans le dernier couloir, un par tranche de temps.

- `'auto'` (la valeur par défaut) : autant que la largeur de la colonne le
  permet, environ 2,5rem chacun — les colonnes étroites d'un téléphone en
  empilent moins que celles d'un ordinateur.
- Un nombre : au plus autant (1 : tout un moment chargé derrière un seul
  « +N »).
- `null` : tous, aussi fins soient-ils.

« +N » ouvre un panneau avec les événements qu'il cache.

## Exemple

<CodeTabs>
<Fragment slot="js">

```ts
import { createCalendar } from '@dzcalendar/dom';

const calendar = createCalendar(element, { timeZone: 'Europe/Paris', eventMaxStack: 3 });

// Later: every event, however thin.
calendar.update({ eventMaxStack: null });
```

</Fragment>
<Fragment slot="angular">

```ts
import { Component } from '@angular/core';
import { DZ_CALENDAR } from '@dzcalendar/angular';

@Component({
  selector: 'app-agenda',
  imports: [DZ_CALENDAR],
  template: `<dz-calendar timeZone="Europe/Paris" [options]="{ eventMaxStack: 3 }" />`,
})
export class Agenda {}
```

</Fragment>
<Fragment slot="react">

```tsx
import { DzCalendar } from '@dzcalendar/react';

export function Agenda() {
  return <DzCalendar timeZone="Europe/Paris" eventMaxStack={3} />;
}
```

</Fragment>
<Fragment slot="vue">

```vue
<script setup lang="ts">
import { DzCalendar } from '@dzcalendar/vue';
</script>

<template>
  <DzCalendar time-zone="Europe/Paris" :options="{ eventMaxStack: 3 }" />
</template>
```

</Fragment>
</CodeTabs>

En Angular et en Vue elle va dans `options` ; en React c'est une prop.
