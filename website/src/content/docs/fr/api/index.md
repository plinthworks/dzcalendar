---
title: API
description: La référence de chaque paquet, générée à partir des types TypeScript.
---

La référence de l'API — `createCalendar`, l'instance du calendrier, le noyau,
les commandes, les composants des frameworks — sera générée à partir des types
TypeScript, pour ne jamais s'écarter du code.

:::note[En cours de rédaction]
D'ici là, les types eux-mêmes font référence : `packages/dom/src/calendar.ts`
(`CalendarOptions`, `CalendarUpdate`, `CalendarInstance`) et
`packages/core/src/index.ts`. Les commandes sont décrites par un schéma JSON,
[`site/commands.schema.json`](https://github.com/plinthworks/dzcalendar/blob/main/site/commands.schema.json).
:::
