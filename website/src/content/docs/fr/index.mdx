<CardGrid>
  <Card title="Des fuseaux, pour de vrai" icon="clock">
    Les instants sont des valeurs Temporal ou des chaînes ISO 8601 avec un fuseau IANA. Aucun `Date`. L'appel de Chicago est dessiné à 17 h à Paris ; le dimanche 25 octobre compte 25 heures.
  </Card>
  <Card title="Quatre saveurs" icon="puzzle">
    JavaScript sans framework, Angular (19 à 22, signaux), React (18 et 19), Vue (3.4 et 3.5), et un Web Component pour tout le reste.
  </Card>
  <Card title="Commandes et annulation" icon="list-format">
    Chaque modification est une commande, de simples données. Un glisser, un redimensionnement, un choix de menu sont ces mêmes commandes — vérifiées, annulables, signalées.
  </Card>
  <Card title="Une donnée invalide ne lève jamais d'exception" icon="warning">
    Un événement illisible est écarté et signalé comme un problème, avec un code. Le calendrier continue de s'afficher.
  </Card>
