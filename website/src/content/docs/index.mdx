<CardGrid>
  <Card title="Time zones, for real" icon="clock">
    Moments are Temporal values or ISO 8601 strings with an IANA zone. No `Date` anywhere. The call in Chicago is drawn at 17:00 in Paris; Sunday 25 October has 25 hours.
  </Card>
  <Card title="Four flavours" icon="puzzle">
    Plain JavaScript, Angular (19 to 22, signals), React (18 and 19), Vue (3.4 and 3.5), and a Web Component for everything else.
  </Card>
  <Card title="Commands and undo" icon="list-format">
    Every change is a command, plain data. A drag, a resize, a menu choice are the same commands — checked, undoable, reported.
  </Card>
  <Card title="Bad data never throws" icon="warning">
    An event that cannot be read is left out and reported as a problem with a code. Your calendar keeps drawing.
  </Card>
</CardGrid>
