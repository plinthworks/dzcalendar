# Languages

Two kinds of words appear in a calendar.

- **Dates, months, weekdays, times, numbers**: from the browser's `Intl`, in
  every language, with no import. `locale: 'ja-JP'` writes Japanese dates
  today. The calendar turns right to left by itself for Arabic, Hebrew,
  Persian and Urdu (from the locale's text direction).
- **The calendar's own words** — "Today", "+3 more", the context menu, what a
  screen reader is told: English and French are built in; Arabic, Spanish and
  German are one import each, paid for only when imported:

```ts
import '@dzcalendar/dom/locales/ar';   // also: …/locales/es, …/locales/de
createCalendar(host, { locale: 'ar-SA' });
```

A locale is found by its exact tag (`ar-SA`), then its language (`ar`), else
English. Unicode extensions (`ar-SA-u-ca-islamic-umalqura`) do not change the
words.

## Changing a few words

`messages` takes only what changes; the rest stays the locale's:

```ts
createCalendar(host, { locale: 'fr-FR', messages: { today: 'Ce jour', noEvents: 'Rien de prévu' } });
calendar.update({ messages: { today: 'Maintenant' } });
```

## Another language, or a region's own wording

```ts
import { EN, defineLocale } from '@dzcalendar/dom';

defineLocale('pt', { ...EN, today: 'Hoje', previous: 'Anterior', next: 'Próximo' /* … */ });
defineLocale('de-CH', { ...DE, today: 'Hüt' });   // a region: wins over `de` for de-CH
```

`defineLocale` also takes a function of the full locale, called once per
locale: numbers then follow it — `ar-SA` counts in Arabic-Indic digits like its
dates, `ar-SA-u-nu-latn` in Latin ones. The built-in `ar`, `es` and `de` are
such functions (`messagesAr(locale)`…; `AR`, `ES`, `DE` are their words for the
bare language).

```ts
defineLocale('pt', (locale) => {
  const n = new Intl.NumberFormat(locale);
  return { ...EN, today: 'Hoje', moreLink: ({ count }) => `+${n.format(count)} mais` /* … */ };
});
```

`DzMessages` lists every key; TypeScript says when one is missing. Keys that
take parameters are functions — counts go through `Intl.PluralRules` and
`Intl.NumberFormat` for the language (the Arabic file shows the six plural
forms and the isolation of left-to-right fragments such as times, with
U+2068 … U+2069, inside right-to-left sentences).

`messagesForLocale(locale)` returns the words the calendar would use.
